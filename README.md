Pipeliner CRM provides a visual sales pipeline and customer relationship management platform that helps businesses track leads, manage contacts, and automate sales processes. The solution offers customizable pipelines, activity tracking, reporting, and integration capabilities, enabling teams to improve productivity and close deals more efficiently. It serves a range of industries with a focus on sales automation and pipeline visibility, delivering a cloud‑based CRM experience.

**Areas:** CRM · Sales · Automation · Pipelines · Cloud

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Pipeliner CRM: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
